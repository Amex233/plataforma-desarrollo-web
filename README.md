# Plataforma de Desarrollo Web

## 1. Descripción del proyecto

La Plataforma de Desarrollo Web es un proyecto educativo desarrollado con React que busca apoyar a los estudiantes en el aprendizaje de tecnologías y herramientas utilizadas en el desarrollo de páginas web.

El sitio organiza recursos educativos, herramientas de programación e información sobre la metodología Scrum para facilitar la consulta y el seguimiento del proyecto.

## 2. Tecnologías utilizadas

- React
- JavaScript
- HTML
- CSS
- Vite
- Git y GitHub

## 3. Funcionalidades desarrolladas

- Interfaz principal y menú de navegación.
- Sección de objetivos de aprendizaje de HTML, CSS, JavaScript y React.
- Recursos educativos con búsqueda y filtros.
- Información sobre herramientas de desarrollo web.
- Sección informativa sobre la metodología Scrum.
- Product Backlog y Sprint Backlog.
- Calendarización y seguimiento de los Sprints.
- Sección de documentación del proyecto.

## 4. Instalación y ejecución

Para ejecutar el proyecto en un equipo local:

1. Clonar el repositorio de GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar `npm install` en la terminal.
4. Ejecutar `npm run dev`.
5. Abrir en el navegador la dirección local que indique Vite, normalmente `http://localhost:5173/`.
